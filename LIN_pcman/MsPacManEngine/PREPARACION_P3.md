# motor de la plantilla de practica 3

se conservan las fuentes y recursos originales. para ejecutar pacman desde la carpeta Entrega se ha añadido lib/MsPacManEngine-p3.jar con las clases necesarias ya compiladas para Java 8, y las dependencias utilizadas en las pruebas. no se ha alterado el codigo del motor.

abre ../Entrega en Visual Studio Code. las configuraciones de esa carpeta utilizan estos jar sin necesidad de importar el proyecto Maven del motor.
